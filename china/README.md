```
│ Математические каноны             │ ■■■■■■■■■■■■■■■■ 300      │
│ Даосская алхимия (Вайдань)        │ ■■■■■■ 120                │
│ Пространственные автоматы (Ци Мэнь)│ ■■■■ 80                  │
│ Астрономические календари         │ ■■■ 50                    │
└───────────────────────────────────┴───────────────────────────┘
```
~300 алгоритмов — Собрание «Десять математических канонов» (Suanjing Shishu). Сюда входят методы поразрядного извлечения корней, геометрические пропорции без углов Лю Хуэя и Цзинь Цзюшао, а также задачи на распределение налогов по сложным прогрессиям.

~120 алгоритмов — Даосский канон (Daozang). Свитки по алхимии котелка. Это циклические пошаговые рецепты фазовых переходов, завязанные на прогрессии остывания и нагрева по гексаграммам.

~80 алгоритмов — Системы «магического планирования» (Ци Мэнь Дунь Цзя, Лю Жэнь, Тай И). Это чистые дискретные автоматы сдвигов и перестановок, которые рассчитывают траектории движения в пространстве и времени.

~50 алгоритмов — Трактаты по императорской астрономии. Сюда относятся нелинейные интерполяции Го Шоуцзина и Цзу Чунчжи, которые вычисляли аномалии движения планет с помощью разностей высших порядков.
